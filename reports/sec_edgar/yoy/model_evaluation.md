# Revenue-decline model: evaluation

Generated by `src/ml/evaluate_revenue_decline.py`. Proof of concept only; not investment advice.

## Conclusions

- walk_forward: the 5-ratio model has balanced accuracy 0.57, 95% interval 0.48-0.65 (permutation p = 0.0498), only borderline better than chance; it is better than the seasonal rule (0.51, p = 0.075) on 392 test rows with 40 declines.
- unseen_company: the 5-ratio model has balanced accuracy 0.44, 95% interval 0.37-0.51 (permutation p = 0.896), not distinguishable from chance; it is worse than the seasonal rule (0.50, p = 0.985) on 406 test rows with 43 declines.
- walk_forward_unseen_company: the 5-ratio model has balanced accuracy 0.46, 95% interval 0.39-0.53 (permutation p = 0.891), not distinguishable from chance; it is worse than the seasonal rule (0.50, p = 0.846) on 385 test rows with 39 declines.
- Other models below p = 0.05: logreg_margins in walk_forward (balanced accuracy 0.57, p = 0.030).
- Multiple tests: 9 model/scheme combinations were tested; at the 5% level about 0.5 would fall below 0.05 by chance alone. 2 did, 0 of them with p <= 0.01, which chance rarely produces. A single result between 0.01 and 0.05 is weak evidence.
- Overall: the model beats chance in at least one scheme but not consistently, or not by more than the seasonal rule under the strictest validation. Do not rely on it; treat its output as an experimental research signal only.

## Target

- `Next_Period_Revenue_Decline_YoY`: 1 if the next reported quarter's revenue is lower than the same quarter one year earlier (year over year, so seasonality cancels out); 0 otherwise.
- Horizon: next reported quarter (about 3 months).
- Features use only the current quarter's statements. Training rows are limited to labels already known when the test rows' figures became available. Timing uses actual SEC filing dates.

## Models

- `majority_baseline`: Always predicts the most common training label.
- `seasonal_baseline`: Majority training label for quarters ending in the same calendar month (seasonality only).
- `logreg_5_ratios`: Proof-of-concept model: 5 ratios, logistic regression.
- `logreg_margins`: Same model with the two margin ratios only.

## Notes

- Minimum training rows: 10; a test row is skipped when its training set is smaller or has only one class (early dates cannot be evaluated).
- `validate_company_wise.py` trains on other companies at any date, including dates after the test rows; `unseen_company` reproduces that setup for comparison, the stricter schemes do not.
- `validate_date_grouped.py`, `train_revenue_decline_model.py` and `explain_revenue_decline.py` split on a date boundary but do not hold back labels that are not yet observable (e.g. 2025-12-31 labels use March 2026 revenue while NVDA's 2026-01-31 rows are in test). `walk_forward` does.
- In the time-aware schemes the seasonal rule usually scores 0.50 because the data has no earlier December quarter whose outcome was already known at the first December test date, so it cannot learn the December pattern yet. This reflects the short history, not an absence of seasonality (see the decline-rate table).
- With this little data, a single train/test split (as in those scripts) can swing by 0.25 balanced accuracy from one test case; use the pooled results above.
